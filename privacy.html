Privacy policy

instagram-automation is a personal tool used only by its owner.

Google data. The app requests only the Google Drive drive.file permission, which lets it see and change only the files it creates itself. It cannot read any other file in your Drive. It uses this permission solely to save the images it generates, and a log of the prompts used, into a folder in the owner's own Drive.

Sharing. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models. The app has no analytics and no servers of its own.

Image generation. Text prompts are sent to the OpenAI API to create images. No Google Drive data is sent to OpenAI, except that when the owner asks to edit an image, that image is sent to OpenAI to be edited.

Removing access. You can revoke access at any time at myaccount.google.com/permissions.
